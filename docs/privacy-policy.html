VocaGuard Privacy Policy

Last updated: 2026-05-13

1. What VocaGuard Does

VocaGuard is a scam-call detection app for Android. It screens incoming calls, and with your permission, transcribes audio during active calls to detect scam patterns using an on-device machine-learning model.

2. Data Collected and How It Is Used

  • Phone numbers — incoming caller numbers are checked against a local scam database and, if you provide an API key, an optional online reputation service. Numbers you report or whitelist are stored locally.
  • Call audio — transcribed in real time on your device using Android's SpeechRecognizer API. Audio is never stored or sent off-device by VocaGuard.
  • Call transcripts — the text output of speech recognition is stored locally in a Room database (up to 500 recent transcripts). You can delete individual transcripts or all transcripts at any time from the History tab.
  • Caregiver contacts — if you enable Family Guard Mode, you choose contacts to receive scam alerts. These contacts are stored locally and are never sent to VocaGuard servers.
  • Settings — sensitivity level, language preference, whitelist, and API key are stored in SharedPreferences on your device.
  • Crash reports — if crash reporting is enabled in your build, anonymised crash data is sent to Firebase Crashlytics (Google). No call content or transcripts are included in crash reports.

3. Data Shared With Third Parties

  • NumVerify API (optional) — if you enter an API key in Settings, incoming phone numbers are sent to numverify.com over HTTPS for reputation lookup. You can remove the key at any time to disable this.
  • Community blocklist sync (optional) — tapping "Sync Now" downloads a JSON blocklist from the configured server URL. No personal data is uploaded during this download.
  • Community scam reporting (optional, opt-in) — if you choose to report a number as a scam, that phone number is submitted to the VocaGuard community server over HTTPS. No transcript content is included.
  • Family Guard alerts (optional) — when a scam is detected and Family Guard Mode is enabled, an SMS alert and/or an HTTPS webhook notification is sent to your chosen caregiver contacts or webhook URL. The alert contains the detected scam type, confidence level, and timestamp. No call audio or transcript is included.
  • Firebase Crashlytics (optional) — anonymised crash diagnostics are sent to Google if crash reporting is enabled. See Firebase Privacy.

VocaGuard does not use advertising networks or sell data to any third party.

4. Permissions Used

  • READ_PHONE_STATE, READ_CALL_LOG, ANSWER_PHONE_CALLS — required to identify the caller and screen calls before they are answered.
  • RECORD_AUDIO — required for in-call speech recognition. All audio processing happens on-device.
  • POST_NOTIFICATIONS — required to display scam alert notifications.
  • ACCESSIBILITY SERVICE — detects when a phone call window is active. VocaGuard reads no content from other apps.
  • SYSTEM_ALERT_WINDOW (optional) — displays an on-screen warning overlay during a detected scam call. Requires manual grant in Android Settings.
  • SEND_SMS (optional) — sends caregiver alert SMS messages when Family Guard Mode is enabled and a scam call is detected.
  • INTERNET — used only for the optional NumVerify lookup, community blocklist download, community scam reporting, Family Guard webhooks, and OTA model updates.
  • RECEIVE_BOOT_COMPLETED — restarts background protection automatically after device reboot.

5. Data Retention and Deletion

All data is stored exclusively on your device. You can:

  • Delete individual transcripts from the History tab.
  • Export and then delete all transcripts using the Export button.
  • Remove your API key and caregiver contacts from the Settings tab.

Uninstalling VocaGuard removes all locally stored data.

6. Data Security

All network communication uses HTTPS. Cleartext (HTTP) traffic is blocked by the app's network security policy. The local Room database uses Android's built-in storage encryption where available.

7. Children's Privacy

VocaGuard is not directed at children under 13 and does not knowingly collect data from children.

8. Changes to This Policy

Updates will be reflected on this page and in the app's Settings screen with a revised "last updated" date. Continued use of the app after an update constitutes acceptance of the revised policy.
