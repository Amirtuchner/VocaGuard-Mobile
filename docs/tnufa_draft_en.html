1. Executive summary

VocaGuard is an Android app for real-time protection against telephone scams (vishing), aimed primarily at the elderly and vulnerable. Unlike existing solutions that rely on number blocking (static blacklists), VocaGuard analyzes the content of the live call in real time and alerts the user while the call is still in progress — before harm is done.

The core technology is a unique hybrid architecture:

  1. On-device ML classifier — fast, private, works offline.
  2. Real-time server engine — multilingual transcription (Whisper) + a knowledge-based confirmation layer, analyzing both sides of the live call.

It overcomes a fundamental Android limitation (apps cannot capture call audio) by routing the call through VocaGuard's infrastructure (conditional call forwarding → SIP bridge → analysis), enabling two-party real-time analysis that is impossible with an on-device-only approach.

Achieved so far (working proof of feasibility): a complete end-to-end system in production, a live app on Google Play across [N] devices, an on-device classifier at 93.4% accuracy (held-out test set), a server confirmation layer with 0% false positives, and live mid-call detection at a measured latency of ~16 seconds.

3. Solution & technological innovation

3.1 Hybrid architecture (on-device + server)

  • Layer A (on-device): a lightweight text classifier (TensorFlow Lite, 14 classes: legitimate + 13 scam types) running locally — fast, privacy-preserving, works offline.
  • Layer B (server, real-time): multilingual transcription (Whisper) + a knowledge-based scoring engine that detects scam patterns and pushes an alert (FCM) to the user during the call.
  • The combination is designed so the high-precision knowledge layer (0% false positives) confirms the ML output (broad coverage), reducing false alarms — see §4.

3.2 The technological breakthrough: two-party live-call analysis on Android

Android blocks apps from capturing call audio (the reason the Accessibility approach was removed). VocaGuard solves this by routing the call through the infrastructure: conditional call forwarding → DID number → Asterisk → bridge back to the app (SIP). During the bridge, a MixMonitor component mixes both channels (caller + user) into a single stream analyzed in real time. This capability is what differentiates VocaGuard from any on-device solution.

3.3 Multilingual

Transcription auto-detects the language (Hebrew/Russian/Arabic/English/mixed) and locks it for the call — critical for the multilingual Israeli market.
